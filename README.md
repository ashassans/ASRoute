# AS ROUTER — Unified AI Gateway

ব্যক্তিগত ও টিম ব্যবহারের জন্য একটি অল-ইন-ওয়ান AI গেটওয়ে (Multi-Provider Fallback, Quota Control, API Key Vault & Monitoring)।

---

## 🚀 কীভাবে চালু করবেন (How to Run)

যেহেতু প্রজেক্টটি লোকালি আপনার নিজের ব্যবহারের জন্য রেডি করা হয়েছে, চালু করা অত্যন্ত সহজ:

### ধাপ ১: ডিপেন্ডেন্সি ইনস্টল করুন
টার্মিনালে কমান্ডটি দিন:
```bash
npm install
```
*(যদি `bun` ব্যবহার করেন, তবে `bun install` দিতে পারেন)*

### ধাপ ২: সার্ভার চালু করুন
```bash
npm run dev
```

### ধাপ ৩: ব্রাউজারে ওপেন করুন
ব্রাউজারে গিয়ে এই লিংকে প্রবেশ করুন:
👉 **http://localhost:3000**

---

## 🔑 এপিআই কী সেটআপ (API Key Setup)

- আপনার যদি Google Gemini API Key থাকে, তবে `.env` ফাইলে `GEMINI_API_KEY="আপনার_কী"` বসিয়ে দিতে পারেন, অথবা
- সরাসরি ব্রাউজার ড্যাশবোর্ডে **Providers** ট্যাবে গিয়ে আপনার OpenAI, Gemini, Claude, Groq বা DeepSeek কী যুক্ত করতে পারেন।
